Combobox shows what matched. While typed text is filtering the list, the first run of each option's label that matches it (case-insensitive) is set in the medium weight. A committed choice fills the input with its label and marks nothing, and an option that matched some other way, such as through an accent, is left plain. Filtering, selection and the options' accessible names are unchanged.
