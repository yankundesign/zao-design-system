The instructions below describe the existing study mechanism. Quiet instrument's study ID and local palette remain in use; radius and fast motion inherit the approved Su tokens. The individual Button, Card, Menu, Tabs, Switch, and Dialog approvals above supersede their earlier study treatments. Other component recipes remain observations of the current study, not system-wide commitments.

Each visual study lives in `explorations/su-studies/<slug>/`, where `<slug>` is lowercase kebab case (`a-z`, `0-9`, and single hyphens). Add both files:

```text
explorations/su-studies/<slug>/
  style.css   # scoped preview styles
  design.md   # intent, decisions, and what to judge
```

The component docs use **Quiet instrument** automatically for Su, with no style selector. They read `explorations/su-studies/quiet-instrument/style.css` and its `design.md` directly. The CSS is served from `/api/style-studies/quiet-instrument/css`; the notes appear once under Foundations → Design notes. The header offers System, Light, and Dark for Su. Yu is absent from the current docs previews and deferred as a possible phase 2. Other Su study folders remain as exploration records and are not shown in the component preview.

Scope every selector under `.study[data-study='quiet-instrument']`. This keeps the study from changing the docs shell or published defaults. Style the real components through their stable hooks:

| Component     | Hooks                                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Button        | `[data-zao-component='button']`, `[data-zao-variant='primary\|secondary\|quiet']`, `[data-zao-size='small\|default\|large']`, inner `[data-zao-slot='face']` |
| TextField     | `[data-zao-component='text-field']`, `[data-zao-slot='label\|control\|description\|error']`, `[data-zao-size='small\|default\|large']`                       |
| Choice fields | `[data-zao-component='combobox\|select']`, `[data-zao-field-frame]`, `[data-zao-slot='viewport\|reveal-edge\|item\|indicator-space']`                        |
| Card          | `[data-zao-component='card']`                                                                                                                                |

The shared specimens also expose `data-zao-specimen='button|text-field|card'`. For compatibility with Quiet instrument, they retain `.study-button` and `.is-primary/.is-secondary/.is-quiet` on buttons, `.field` and `.field-invalid` around fields, and `.system-card`, `.card-topline`, `.card-main`, and `.card-foot` in the card. Prefer the `data-zao-*` hooks in new CSS; use specimen classes only for study-specific composition.

Keep `style.css` and `design.md` together and record how the style handles Button, TextField, and Card. The study remains local CSS; choosing a study does not change published tokens.
