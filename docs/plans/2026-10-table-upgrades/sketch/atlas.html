Table Interaction Atlas

Thirteen working studies of what a table can do when you scroll it, sort it, point at it, feed it live data, or hand a column to an agent. Each plate links to where the idea comes from and says how it sits with ZAO's Table. All data is sample data.

Motion

Frequency sets the budget

What people do hundreds of times a day, like arrow keys, J/K and keyboard sorts, lands instantly. Rare moments may move.

Motion answers a question

Where did that row go? What just changed? Which group am I in? If an effect answers none of these, cut it.

Every effect has a still form

Reduced motion keeps the information as marks, counts and tone, and drops the travel. Flip the Motion switch to compare.

Scroll

What the table tells you while it moves under your hand.

1.1

Stuck header

Fits
RequestIDOwnerItems
Header restingGroup Today

Try: scroll the table.

What
Once the column header sticks, its rule darkens to frame weight and a soft plane appears under it. Day headers stack beneath it; a mark shows the current group and the readout names it.
Seen in
Chrome's scroll-state demos (stuck headers, table shadows) · ics.media's scroll-state guide · MDN.
How
@container scroll-state(stuck: top) on the sticky header styles its children (Chrome 133+); scrolled adds direction (Chrome 144+). Elsewhere, a scroll listener sets data-stuck, as here.
For ZAO
The frame stays still; only the header's rule changes weight. It follows the line hierarchy from the craft research: frame versus division.
1.2

Edge cues and a frozen column

Fits
RequestIDOwnerRegionItemsSeatsUpdatedStatusApprover
Columns

Try: scroll sideways, or click a block in the column map.

What
The frozen first column casts a shadow only once content slides under it; a shade on the right says more columns wait. The column map shows which columns are in view.
Seen in
Lea Verou's scrolling shadows (2012) · Dave Rupert's animation-timeline version (2023) · Roman Komarov's scroll shadows · Bramus's scroll-driven animation demos.
How
CSS only with background-attachment: local, or a scroll-driven animation: scroll(self inline) on the scroller and scroll(nearest inline) for the sticky cell. Chrome 115+ and Safari 26 run these; Firefox still has them behind a flag. Here a scroll listener sets two CSS variables.
For ZAO
Fits the existing keyboard-scrollable region. The column map is a small new instrument, in the spirit of Oxide's readouts.
1.3

Marked scroll rail

New part
RequestIDOwnerStatus
Rows

Try: click a tick to jump, or drag along the rail to scrub.

What
A slim rail stands in for the scrollbar. Long ticks mark Needs review, short ticks mark Blocked, a bracket shows where you are, and the readout counts the rows in view.
Seen in
Google Photos' date scrubber · scrollbar annotations in DevExpress and ComponentOne grids · search-match marks in code editors · Devouring Details' tick ruler.
How
Each tick sits at its row's offset divided by the scroll height. The region stays keyboard-scrollable and the ticks are real buttons.
For ZAO
Close to ZAO's own marks (ticks, fishtails) and the storage ring's mark field. A new part; it would need its own spec.
2

Reorder

Motion that answers where a row went.

2.1

Sort glide

Your call

Try: click headers, then Tab to one and press Enter.

What
Rows glide to their new places when you sort with the pointer, so your eye can follow one row through the change. A keyboard sort lands instantly.
Seen in
Dave Bitter's View Transitions demos (sort, filter, add, remove) · Emil Kowalski, "You don't need animations": keyboard-initiated actions shouldn't animate.
How
FLIP: measure rows, reorder the DOM, play each row from its old offset to zero. Or wrap the update in document.startViewTransition() with a view-transition-name per row. Here: 270 ms (grade 1) on the fold curve; event.detail === 0 marks a keyboard click.
For ZAO
Moves rows, and the approved Table keeps rows stationary. Could be opt-in on Table.Root.
2.2

Filter fold

Your call
Showing of 20
RequestIDOwnerStatus

Try: switch filters quickly; a new filter cancels the old one mid-way.

What
A filter change plays in three beats: leaving rows fade (135 ms), the rest close the gap (225 ms), arriving rows fade in. The count rolls to its new value.
Seen in
Rauno Freiberg, "Designing Depth" (choreography: what's nearest the change moves first) · Dave Bitter's View Transitions demos.
How
Exit, move, enter, in that order, each on a ZAO grade. Cancel the previous run when a new filter arrives.
For ZAO
Moves rows; same decision as 2.1.

Point and select

Feedback for the hand: what you're on, what you've picked, what you can do next.

3.1

Crosshair

Fits
Department
Point at a cellSeats used

Try: move across the cells, or focus the table and use arrow keys.

What
Pointing at a cell lights its row, its column and both headers, so a value reads against both axes.
Seen in
Jhey Tompkins' :has() table highlight · hyper-text.org's write-up (in Japanese) · CSS Script's crosshair table.
How
tr:hover for rows; columns with table:has(td:nth-child(3):hover) td:nth-child(3), one rule per column, or a few lines of script.
For ZAO
Neutral tone only, no change in geometry, as in the approved hover rules.
3.2

Range select and action bar

Fits
RequestIDOwnerStatus
selected

Try: click a box, Shift-click another, or press and drag down the boxes.

What
Click, Shift-click a range, or paint by dragging down the boxes. An action bar rises with a rolling count, and the action's label changes as it works: Approve 3, Approving, Approved 3.
Seen in
Shift-click ranges in Gmail and file managers · Benji Taylor's Family Values on morphing labels · the label-morph idea in ZAO's craft research.
How
Native labeled checkboxes underneath; range and paint sit on top. The count is a live region.
For ZAO
Selection stays on explicit checkboxes, as the approved Table requires.
3.3

Cell cursor

Grid only
Click a cell, then hold an arrow key

Try: Shift+arrows to extend, ⌘/Ctrl+C to copy, Esc to clear.

What
A spreadsheet cell cursor. In Glide it travels between cells; in Instant it jumps. Hold an arrow key in each mode to feel why fast, repeated moves should not animate. The readout sums a range; copying draws marching ants.
Seen in
Excel's animated cell cursor (people ask how to turn it off) · Emil Kowalski on keyboard actions.
How
One absolutely placed cursor over the grid, moved with transforms. Ants: an SVG rectangle with an animated stroke-dashoffset.
For ZAO
Only for a future editable grid; the current Table has no cell focus.
3.4

Peek

Fits
RequestIDStatus
Click a row, then press Space

Try: tap Space to toggle, hold it to look, J/K to move.

What
Tap Space to open a preview of the focused row; hold Space to look only while held. J/K or arrows move through rows and the preview follows instantly.
Seen in
Linear's Peek (tap or hold Space in any list) · macOS Quick Look.
How
A press longer than about 280 ms counts as a hold. The panel animates only when it opens or closes, never when its content changes.
For ZAO
A peek could open where the assistant panel sits in the workspace.

Live values

Tables that change while you watch.

4.1

Change flash and rolling digits

Fits
SiteActive callsJoins / minLoss %
Updating every 1.4 s

Try: watch a few seconds, then switch Motion to Reduced.

What
When a value changes, its cell flashes a tone and fades, the digits roll in the direction of change, and the size of the change shows briefly beside it.
Seen in
AG Grid's flashing cells and its show-change and slide cell renderers · NumberFlow by Maxwell Barvian.
How
AG Grid holds its flash class for 500 ms and fades over 1,000 ms by default. Here the flash is tone, not color; direction comes from the roll and the sign. Updates pause offscreen.
For ZAO
Matches "readings tick only when data changes" from the craft research.
4.2

Live tail

Fits
TimeEventActorResult
Following

Try: scroll up while rows arrive, then use the pill to get back.

What
New rows arrive at the bottom. While you're at the bottom the table follows; scroll up and it holds still and counts new rows in a pill that takes you back.
Seen in
Live tail in log tools · a write-up on "smart following" for log views.
How
One following flag that ignores the table's own scrolls; following resumes within a row of the bottom. New rows get a fading mark at the edge, not a slide.
For ZAO
Fits audit logs and an agent's activity feed.

Agent work

Cells an agent fills, shown so you can follow the work and check it.

5.1

Agent fills the columns

Fits
Document Renewal date Seat cap Auto-renews
Waiting to run

Try: point at a page mark (p.4) to read the passage; a dashed ? explains a gap.

What
An agent answers one question per column for each document. Cells go from queued to reading (with the page it's on) to answered, and each answer carries a page mark that shows the quoted source. When a document doesn't say, the cell says so.
Seen in
Hebbia Matrix (rows are documents, columns are questions, answers link to passages) · Clay's run progress (column and table progress bars) · Paradigm (an agent in every cell).
How
A work queue with four concurrent runs, in reading order. The header shows progress per column. Answers type in; Reduced shows them whole.
For ZAO
The plate closest to ZAO's agent-friendly aim: autonomous work you can follow and verify. Sample documents.
6

Focus and context

An idea from 1994 that still feels new.

6.1

Table Lens

Exploration
Point at the bars60 sites

Try: move down the bars, then sort by another column to see its shape.

What
Every row compresses to a bar, so the whole table fits; pointing opens a lens where nearby rows grow back to readable size.
Seen in
Table Lens (Rao and Card, CHI 1994) · LineUp's ranking tables · Bertifier, after Bertin's reorderable matrices.
How
Each row's height depends on its distance from the focus; the focus is the row whose center lands nearest the pointer.
For ZAO
Not for the default Table. Useful for long scans, like license use across sites.
