# Explorations

Working material for exploring ZAO's direction and polishing Su's craft in light and dark. Read the [root agent guidance](../AGENTS.md) and the [current design direction](../BRIEF.md#current-design-direction-quiet-construction) before starting work. The lab runs locally with `pnpm lab`.

As of October 6, 2026, **Quiet construction** is the overarching experimental direction: exploring the boundary between 2D and 3D interfaces through clear, measured, physically coherent forms and quiet responsiveness. It is not a third finish. A designed resting state may already contain depth, and Su light and dark share the same structure and interaction meaning. As of Oct 7, Yu is deferred as a possible phase 2; its existing assets are groundwork, not current exploration scope.

The theme comes first; Yankun will define interactions one by one. Until a specific component task is requested, work here is documentation and research. Do not turn the direction into prescribed hover gestures, depth values, timing, or a global motion system. Usability benefits are hypotheses to investigate. Earlier work packages and available lab tools are not an automatic implementation queue.

The repo includes style JSON in `styles/`, reference metadata in `references/index.json`, snapshots in `snapshots/`, and session notes in `journal/`. Reference images in `references/files/` and trial font files in `fonts/` stay on this machine and are ignored by git. The same applies to product recreations in `apps/lab/specimens/local/` and their captures in `snapshots/private/`.

The current Su baseline comes from the token build. Existing Yu support is retained as deferred groundwork. They are never copied into style files. Save a fork when you want to keep changes.

Quiet instrument remains an existing study and docs preview. Keep its `quiet-instrument` slug, CSS, and token values; they are not approved system behavior. The docs site consumes its [design notes](su-studies/quiet-instrument/design.md) from Markdown, so update the source notes for direction or copy changes. Keep the distinction between current direction, study evidence, and individually approved interactions clear.
