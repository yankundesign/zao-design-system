# Explorations

Working material for finding Su and Yu's style. The lab runs locally with `pnpm lab`.

The repo includes style JSON in `styles/`, reference metadata in `references/index.json`, snapshots in `snapshots/`, and session notes in `journal/`. Reference images in `references/files/` and trial font files in `fonts/` stay on this machine and are ignored by git. The same applies to product recreations in `apps/lab/specimens/local/` and their captures in `snapshots/private/`.

The current Su and Yu baselines come from the token build. They are never copied into style files. Save a fork when you want to keep changes.
